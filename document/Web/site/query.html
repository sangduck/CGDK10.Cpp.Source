Query system server.query*.h, server.query/, build/src/server.query/

공통

  • Iquerier: set_max_retry_on_fail(≤64), register_querier(), 통계 query::statistics::Nquerier(try, success, fail, retry, alloc/free/create/destroy session, processing, using, exist 게이지 — reset 으로 지워지지 않음). query::manager_querier 싱글턴, print_statistics(). Iserver_query::process_execute_query() / process_reset_session(). execute_result<T> 는 co_await 또는 동기. numeric.h decimal 타입.

ODBC — query::rdb::odbc::querier

  • START_PARAMETER{provider(eDB_PROVIDER: SQL Server / MySQL 변형), data_source, user_id, password, initial_catalog, character_set, count_session = 32, count_data_source, keepalive, session_wait_timeout(MySQL)}. start(param | connection_string | provider…).
  • 실행 execute_query(), execute_query_sync(), co_execute_query(), co_post_execute_query(), post_execute_query(cmd, lambda, on_cancel), prepare_query(). cancel_queries() 는 큐에 있는 post 를 on_cancel 로 정확히 1회 통지. 실행은 락 밖, 풀은 private.
  • 세션 alloc_session / post_alloc_session / co_alloc_session / co_post_alloc_session / free_session. 결과 Nquery: move_first, move_next, get_next_result, set_param / get_param, get_ordinal(col), get_result<T>(), 행 get_value<T>(ordinal | name).
  • 구조체 get_value(query_ODBC_GET_VALUE.h): is_struct_serializable_v<T> 인 비다형 aggregate 를 any_constructor_get_value 기법으로 연속 컬럼에서 채운다(2023.09 추가).
  • 트랜잭션 transaction_guard, 매크로 scoped_transaction(psession) / commit / rollback. ODBC 드라이버: unixODBC + MySQL/MariaDB ODBC(odbc.ini, odbcinst.ini). OLEDB 는 제거되어 ODBC 단일(r11372~).

Redis — query::redis::querier

  • START_PARAMETER{remote_endpoint, count_session = 32, wait_seconds, pio_context}. execute / sync / co_ / post 메서드는 포맷 인자를 받는다.
  • alloc_query() 는 전용(스택에서 미사용 세션을 꺼냄), alloc_shared_query() / post_execute_query 는 공유(스택 세션 재사용). 대기는 FIFO, 막힌 공유 요청은 100 ms 후 세션을 공유. cancel_query(). push+send 는 세션 락(r11335, r11346).
  • RESP: eRESP_DATA_TYPE(+ - : $ *), resp_data 트리(vector_child, is_success()), 쿼리의 result(). Windows 는 vcpkg redis-plus-plus 도 있고 예제 8.1.bench_redis 가 둘을 비교.

HTTP · WAL
