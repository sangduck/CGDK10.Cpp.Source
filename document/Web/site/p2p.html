P2P system net.p2p.h, net.p2p/p2p/, build/src/net.p2p/

  • 구현된 것: net::io::Ipeer, group_peer::Narray<TPEER>, socket::Ndummy, connectable::Ndummy, datagram sender 변형 sender::Ndatagram_address / Ndatagram_null_address / Ndatagram_proxy, send_request::Nproxy.
  • TURN: net.p2p.turn.client.h / net.p2p.turn.server.h 는 모든 include 가 주석 처리되어 있고, turn.client / turn.server 헤더 디렉터리는 비어 있으며 cpp 는 2줄 스텁. MFC relay 서버 껍데기(turn.relay_server.mfc)만 존재. 미구현.
  • 빌드: vcxproj 로만 CGDK10.net.p2p, net.p2p.turn.server 가 만들어진다. build/src/net.p2p/CMakeLists.txt 는 alias 만 정의해 Linux CMake 는 p2p 를 빌드하지 않는다. unit_test/ 는 CMakeLists 만, 튜토리얼 network.2.p2p 는 비어 있음.
