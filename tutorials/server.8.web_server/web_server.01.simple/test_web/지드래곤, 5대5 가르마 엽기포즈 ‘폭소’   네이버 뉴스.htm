지드래곤, 5대5 가르마 엽기포즈 ‘폭소’

기사입력 2014-07-22 20:47
기사원문 93


[OSEN=김사라 기자] 빅뱅 지드래곤이 엽기 사진으로 웃음을 자아내고 있다.

지드래곤은 22일 오후 자신의 인스타그램을 통해 이모티콘과 함께 한 장의 사진을 게재했다.

공개된 사진 속 지드래곤은 완벽한 5 대 5 가르마를 한 채 찡그린 표정으로 카메라를 응시하고 있다. 세련되게 치장한 패션과는 상반되는 엽기적인 모습이 웃음을 유발한다.

이를 본 네티즌은 “지드래곤 뭐하나”, “지드래곤 장난꾸러기”, “지드래곤 재미있는 사람이다” 등 다양한 반응을 보이고 있다.

한편 빅뱅은 내달 15, 16일 양일간 서울 잠실종합운동장에서 열리는 ‘AIA 리얼 라이프: 나우 페스티벌 2014(AIA Real Life: Now Festival 2014)’에 참여한다.
