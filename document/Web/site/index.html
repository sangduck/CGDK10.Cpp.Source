CGDK10 — CGC.II. 서버 엔진

저장소 CGDK10.C++.public 의 헤더·소스·빌드 스크립트·테스트를 직접 읽어 정리한 문서. C++20, Windows x64(IOCP/RIO) · Linux(epoll/io_uring). 네임스페이스 CGDK, 공개 헤더 include/cgdk/sdk10/, 소스 build/src/<모듈>/.

기술적 설명

모듈과 하부 메뉴의 대응: Executor · Pool · Object · Log(system 측) 는 system 모듈(system.object.h), Socket 은 net.socket, P2P 는 net.p2p, Update 는 net.update, Server · Group · Log(server 측) 는 server.system, Query 는 server.query.
