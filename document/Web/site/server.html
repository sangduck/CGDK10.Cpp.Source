Server system server.service.h, server.time_event.h, server.system/service/, build/src/server.admin/, server.service/doss, server.web, server.http_api

service

  • 체인 Iservice(Istate + Iinitializable + Istartable + Inameable + Imessageable) → Nservice(+ Ninitializable_startable, Npausable, Nstatic_service_logger) → Xservice(파생 대상). Nservice_application / service_application<T>(싱글턴), Iservice_component(on_service_complete_initialize/start/stop/destroy).
  • 생명주기 initialize(context) → start(context) → stop() → destroy(), pause/resume, wait_destroy(timeout). 단계별 _process_initializing_pre/post, _process_destroying_pre/post 등 훅, 설정 훅 on_initialize_setting / on_start_setting. 설정은 JSON context(서비스 수준 START_PARAMETER 구조체는 없음).
  • Xservice::run(argc, argv, setting_file, fn_console_key): 콘솔 모드는 Ctrl-X 종료. --install / --uninstall / --start / --stop [name] 으로 Windows SCM 서비스 또는 systemd unit 관리, --account, --password, --no-restart, --setting <file>. 종료 대기 stop_grace_period(기본 60 s).
  • admin 연동: m_psocket_to_admin(server_system::socket::client), host/service instance manager. 처리 메시지 SERVER_ADMIN_REQUEST_{UPDATE_SETTING, INIT, DESTROY, START, STOP, PAUSE, CONTINUE}_SERVICE, send_to_admin_server(), on_server_certified(). socket_to_admin 설정이 없을 때만 is_start_on_run() 이 true.

time_event

  • 싱글턴 time_event::entity_manager(instance()): register_entity, unregister_entity(ptr|id), unregister_event_all, register_class, executor(), print_statistics().
  • 엔티티 entity_iteration<F>(set_event_time / set_event_interval / set_event_times / set_event_function(result_code(utc::time_point))), entity_start_end<F>, entity_start_iteration_end<F>, entity, event. eTYPE {ONCE, ITERATION, START_END, START_ITERATION_END}. start() 등록, stop() 해제, entity_status()(state, count_try, count_succeeded, count_failed).
  • 서비스 생명주기 연동 객체 server.time_event.{object,schedule}.service_{init,start,stop,destroy}.h. 테스트 17개, 튜토리얼 server.4.time_event.

admin (build/src/server.admin)

  • 체인 service → host_agent(:22044) → admin_server(:21887). admin_server 는 certify, instance 상태, REQUEST_xxx 중계, desired-state 파일, 재시작 정책(interval, max count, window), HTTP 제어 API(기본 127.0.0.1:21888, certify key·허용 주소·서명), event_command 훅(host_connected, service_down, crash_loop …), 콘솔 명령. host_agent.service 는 host/server/network/querier 정보를 websocket observable 로 게시.
  • 테스트 unit_test.server_admin.admin_server 32개(desired state, 재시작, HMAC, rate limiter, web session, audit 27 + fuzz 5), e2e run_admin_e2e.{sh,ps1}. 빌드는 vs 솔루션 admin_server, host_agent.service. 헤더 server.admin.version_control.h(admin::SVN)는 존재하지 않는 경로를 include 하는 stale 파일.

doss (server.service.doss.h)

  • DOSS = Distributed Object Storage System. 엔티티의 체크인/체크아웃 소유권과 직렬화된 트랜잭션. ID sREPOSITORY_ID, sENTITY_ID{repository, object}(make_entity_id), sSESSION_ID, sCHECKIN_ID. eTRANSACTION_TYPE {CHECKIN, COMMAND, UPDATE, CHECKOUT, CREATE, REMOVE}, eTRANSACTION_OPTION {EXCLUSIVE_CHECKIN, REJECT_IF_ALREADY_EXIST, ALLOW_DUPLICATED_CHECKIN, TRANSFER_CHECKIN}.
  • doss::session<TENTITY>: co_checkin(entity_id[, repository]), co_request(transactable), co_checkout()(.get() 대기 / .start() fire-and-forget), 동기형 checkin / request / checkout 은 PENDED 반환, cancel(), 콜백 on_entity_checkin / on_entity_command. session::destroy() UAF 는 r11333 수정.
  • Irepository 훅(코루틴) on_request_checkin / checkout / command / update — set_result() 후 co_return. 구현 Nrepository<T>(checkout_all), repository::rdb, orm, remote(기본 포트 31001, ack 기반 복구), Nhub. Ientity / entity_transactable 이 트랜잭션을 한 번에 하나씩 코루틴으로 실행. Idepot / Ndepot / depot(set_repository, checkout_all), manager_repository, statistics::Nrepository. 테스트 test_doss_rdb.cpp 3개(checkin → command → checkout).

web · http_api

  • server.web: net::socket::web_server 가 http request / websocket 을 server::web::Ientity 트리로 라우팅. 노드 entity::folder / resource / text / application, process_request(msg, path, sWEB_SERVER_CONTEXT). SSL acceptor net::acceptor_web_server<T>. 튜토리얼 server.8.web_server.
  • http_api: 공급자별 자유 함수 request(const REQUEST_X&) -> RESPONSE_X. bank(오픈뱅킹식 OAuth authorize/token, 계좌 등록·조회·잔액·거래내역, 이체 출금/입금/결과/재확인, 실명 조회, 약 5.6k 줄), kakao(OAuth, Talk, Pay ready/approve/subscription/cancel, Story, Push 선언, 본문 다수 주석), line(토큰, 메시지 reply/push/multicast, 프로필, 그룹/룸, 리치 메뉴). google 은 kakao 골격, apple·naver 는 빈 네임스페이스, oauth/ 는 CMakeLists 만. 영수증 검증 코드 없음.
