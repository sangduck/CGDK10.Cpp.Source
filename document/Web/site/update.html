Update system net.update.h, net.update/update/, build/src/net.update/

  • 파일/리소스 패치 송수신. update::sender(Nsender): add(object_ptr<resource::Iupdatable>). update::receiver(Nreceiver): 훅 on_update_begin / on_update_end, on_updatable_requested / begin / process / end. 람다 변형 sender_lambda, receiver_lambda.
  • 리소스: resource::updatable::file / file_stream / folder, update::resource_manager, md5_caching.
  • receiver 처리(r11391): 수신 핸들러는 파싱·큐잉만 하고, 직렬 system-executor worker 가 MD5 검사·압축 해제·파일 i/o·업데이트 처리를 수행. 큐 바이트 한도 기본 32 MiB(설정 가능), 수신 측 backpressure. stop 은 취소를 큐잉하고 최대 30 초 드레인, worker 콜백은 자기 자신을 기다리지 않음. executor post 실패 시 호출 thread 에서 드레인. UPDATE_BEGIN 오류 응답의 sender/receiver 인자 순서 수정.
  • 서버 앱: build/src/net.update/update.server/{console, windows.mfc}. 예제 7.1.update_service, 튜토리얼 network.3.update(simple_update, resource_manager, update_service). MFC controls network.update.mfc_controls. unit_test/ 는 CMakeLists 만.
