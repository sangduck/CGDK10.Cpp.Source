Object system system.object.h, common/, containers/, include/cgdk/buffers/

참조 카운팅과 포인터

  • Ireferenceable(가상 기반 Idisposable) — atomic int m_counter. add_ref()(relaxed), add_ref_if_alive()(CAS, 0 이면 실패), release(), reference_count(), 가상 on_final_release(). 생성한 Ifactory* 보관(get_factory()).
  • object_ptr<T> — 침입형. reset / detach / move / get, operator T*, operator bool, -> 와 * 에서 CHECK_NULLPTR. 해제 중인 객체의 raw 포인터로 object_ptr 를 만들면 이중 해제가 난다.
  • own_ptr<T> — 소멸 시 destroy() 후 release. any_ptr, OBJ<T>(임의 T 를 Nreferenceable_no_act 로 감싸고 T 가 Idestroyable 이면 소멸 시 destroy).
  • Iobject = Iidentifiable + Inameable + Imessageable. 상태 믹스인 Istate/Nstate, Iinitializable, Istartable, Ninitializable_startable, Ipausable, Ienable, Iupdatable, Idestroyable, Iattachable.

생성

make_object<T>(args...), make_own<T>, alloc_object, mem_alloc(size), alloc_shared_buffer(size), make_shared_buffer(value...). 디버그 빌드는 DEBUG_INFO_SETTER 로 __FILE__/__LINE__ 를 기록. make_object 는 T 가 Npoolable 이면 풀, 아니면 Ireferenceable 파생이어야 하고(static_assert) 로컬 서브클래스 __X : T, REFERENCEABLE_RELEASER 를 new 한다. 그 소멸자는 T 에 destroy() / stop() 이 있으면 호출한다. _USE_DEBUG_NEW, _USE_CREATE_FACTORY_FOR_ALL_OBJECT 가 켜져 있다.

buffer 와 직렬화 (buffer ver 3.03)

  • buffer_view(비소유 커서, 추출용), buffer(bound 있는 view, 추가용), shared_buffer(메모리 참조 보유), const_buffer_view.
  • 쓰기 append<T>(v), append(ptr, count), operator<<, append_text. 읽기 extract<T>(), extract(tuple), front<T>(offset), subtract<T>(), operator>>. skip(n), operator^=(재배치/크기 변경). 타입별 serializer_append / extract / peek, SIZE_OF_t. get_size_of(args...) 로 크기를 미리 계산해 make_shared_buffer(value) 가 한 번에 할당·직렬화.
  • 지원 타입: trivially copyable 은 memcpy. 배열, std::array, tuple, STL 시퀀스/연관 컨테이너(COUNT_T = int32_t 접두), object_ptr, own_ptr, shared_ptr / unique_ptr, 중첩 buffer. 문자열(char, wchar_t, char8_t)은 COUNT_T(길이+1) + 문자 + null, 최대 _XX_MAX_STRING_SIZE = 65536. text<T>("..."_text) 는 접두 없는 raw 텍스트, 문자 타입 간 변환은 _append_text_encoding. _USE_CHAR_STRING 은 CP949 주석.
  • 구조체 reflection: aggregate 에 ENABLE_STRUCT_SERIALIZABLE → reflection::get_fields_count<T>()(aggregate-init 탐지)로 필드 수를 얻어 순서대로 직렬화. DISABLE_STRUCT_SERIALIZABLE 로 제외. 가상 직렬화는 Ibuffer_serializable + DEFINE_BUFFER_SERIALIZE(members...)(process_serialize_in/out, process_size_of, 타입 해시 생성).

context · 메시지

  • context — 계층형 key/value 설정, 자체가 Ibuffer_serializable. find / try_find / [], from_json / to_json, 환경변수 읽기(context.json.cpp). START_PARAMETER 구조체는 context 를 통해 raw 바이트로도 start() 에 전달된다.
  • sMESSAGE{message_t message; any_ptr source}, sMESSAGE_WINDOW. Imessageable::process_message(sMESSAGE&), 디스패치 맵 BEGIN_CGMESSAGE_MAP / DEFINE_PROCESS_MESSAGE(common/message_map.h).
