인터페이스

  • Igroup<TMEMBERBASE>: leave(), parent_group(), lock_group(). Igroup_enterable: enter(member[, param]), enable_member_enter() / disable_member_enter(), is_member_enterable(). Igroup_countable: member_count / capacity / room_count, is_member_full / empty / room.
  • 멤버 믹스인 Igroupable<TMEMBERBASE>: get_group(), is_member_of(), leave_group(param), member_set(), member_serial(), 멤버 락 m_lockable_group. 스냅샷 뒤 다른 그룹으로 옮긴 멤버를 빼지 않도록 member->leave_group() 대신 Igroup<base>::leave(member, param) 를 권장.

락 규칙

락 순서는 멤버 락 → 입장 락(m_lockable_enter) → 그룹 락(Igroup::m_lockable_group). 멤버 둘 이상이면 std::lock. entering 은 멤버+입장 락, entered·leaving 은 멤버+그룹 락, leaved 는 멤버 락 안에서 호출된다. 이 이벤트나 for_each_member 콜백 안에서 다른 멤버 락을 잡으면 교착한다(헤더 주석에 규칙으로 명시). observable 은 observer → m_lockable_observable_enter → m_lockable_observable.
  • 락 타입은 group_lock_object(recursive_mutex 파생). 가장 바깥 unlock 뒤 send_defer 를 flush 하므로 락 안의 send 는 지연된다. std::unique_lock<lock_object> 처럼 타입을 박지 말고 CTAD/decltype 을 쓴다.
  • member_snapshot(server.group.member_snapshot.h): 불변·참조 카운팅 copy-on-write 배열. list / Nmap / array / observable / container 가 lazy 로 유지 — 입장/퇴장 구간 시작에서 게시본을 버리고 읽는 쪽이 없으면 다시 만든다(eager COW 는 2만 명 그룹에서 코어 0.5~2.6개를 먹어 채택 안 함). get_member_snapshot(), for_each_member_snapshot(), for_each_member(), find_member(pred)(그룹 락 밖).
  • 송신 send(...), send_except(member, buf), send_conditional(buf, pred) 는 스냅샷 순회(send_conditional 의 조건은 그룹 락 안). leave_all / sender 는 락 안 스냅샷, 락 밖 처리.
