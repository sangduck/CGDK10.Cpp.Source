Executor system system/object/executor.*, executable.*, schedulable.*, api.io_context.*

인터페이스

  • Iexecutor — post(object_ptr<Iexecutable>), execute(tick_duration, option), thread_blocked() / thread_unblocked(), statistics(). 코루틴이 켜지면(__cpp_impl_coroutine) post(callable[, on_complete]) / execute(callable) 이 coroutine::task 와 람다를 받으며, 소유자 Ireferenceable* 를 붙일 수 있다. executor 자체를 소유자로 넘기면 컴파일 오류.
  • Iexecutable — 가상 함수 하나 intptr_t process_execute(intptr_t result, size_t param). make_executable(lambda) / make_executable(this, &fn, args...)(executable.make.h).

system_executor (정적 싱글턴)

  • initialize_instance(int threads = CGEXECUTOR_AUTO) 또는 initialize_instance(context&)(키 "thread_count", "enable_thread_observer"), destroy_instance(), run_executor().
  • executor()(Iio_context), scheduler(), schedulable_manager().
  • post(exec), post(exec, tick::time_point), post(exec, tick::duration)(scheduler()->post_at 경유).
  • 반복 작업 register_schedulable() / unregister_schedulable(). 종료 훅 register_destroy_handler(name, fn) — 정상 destroy 때만 등록 역순으로 1회.
  • start_factory_garbage_collection()(풀 GC 스케줄), start_thread_observer()(schedulable::system::exception_observer 워치독).

i/o 백엔드

  • executor::io_backend {epoll, io_uring}, set_default_io_backend(), default_io_backend(), is_io_uring_available()(executor.Iio_context.h). Windows 는 항상 IOCP.
  • Linux 기본은 epoll. 환경변수 CGDK_IO_URING=1(true/on) 로 io_uring 선택. io_uring 은 raw syscall(io_uring_setup/enter + mmap, liburing 불필요)이고 IORING_FEAT_EXT_ARG, IORING_POLL_ADD_MULTI, IORING_POLL_UPDATE_EVENTS 가 필요(커널 5.13+). 불가 시 epoll fallback 후 로그.
  • io_uring 백엔드는 epoll 과 같은 준비 이벤트 의미: EPOLLONESHOT ↔ 1회 POLL_ADD, 재무장은 IORING_POLL_UPDATE_EVENTS, listen/UDP/post eventfd 는 multishot. worker thread 가 처리 중 모은 SQE 를 pop_events()/flush_pending() 에서 한 번의 io_uring_enter 로 제출. CQ 는 한 thread 가 소유(m_lockable_cq). 현재는 POLL_ADD 만 쓰므로 syscall 수는 epoll 과 같다(완료 모드는 남은 일).
  • 그 밖의 백엔드 파일: api.io_context.{epoll_direct, epoll_queued, iocp_direct, iocp_queued, rio}.h.
  • thread affinity: api::set_current_thread_affinity()(pthread_setaffinity_np / SetThreadAffinityMask)를 io_context_threads thread 진입에서 호출. thread 는 std::jthread 기반 api::thread / threads.

코루틴

coroutine.task.h, coroutine.post.h, coroutine.sleep.h, coroutine.async_result.h, coroutine.function.h. query 의 co_execute_query, doss 의 co_checkin 등이 이 위에서 동작한다.
