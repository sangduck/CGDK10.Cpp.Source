벤치마크 Release 빌드 측정 모음

사이트에 실린 성능 수치를 한곳에 모았다. 모든 수치는 Release 빌드로 쟀다. 자세한 해석은 각 주제 문서에 있다.

측정 원칙

  • 빌드 : Windows MSVC v145 /O2 /GL + /LTCG, Linux g++ 15.2 -O3 -DNDEBUG. CGDK 라이브러리도 Release(*_Release.lib, lib*_linux.Release.a).
  • 소스 : 측정 시점의 리비전을 svn export 해 공유 작업 사본과 따로 빌드한다. 다른 세션의 미커밋 변경이 섞이지 않는다.
  • 반복 : 비교 대상을 번갈아 돌리고(교대) 중앙값을 쓴다. 다른 빌드나 벤치가 도는 장비에서는 재지 않는다.
  • Debug 값 : 싣지 않는다. Release 로 다시 잴 수 없었던 이전 Debug 표는 내렸다.

log_bench.cpp (펼치기) 
// log bench : the default pipeline (logger_hub_archive -> logger_file), end to end incl. the file writes
//   usage : log_bench <threads> <logs per thread> <rounds>
//   time = from the first LOG_INFO to the end of destroy() of the hub and the file logger (every record written)
#include <string>
#include <vector>
#include <memory>
#include <span>
#include <map>
#include <thread>
#include <atomic>
#include <chrono>
#include <algorithm>
#include <cstdio>
#include <cstdlib>
#include "cgdk/sdk10/server.log.h"

using namespace CGDK;

static double run_once(int _threads, int _logs_per_thread, int _round)
{
	char filename[64];
	std::snprintf(filename, sizeof(filename), "./log_bench_%d_%d.log", _threads, _round);
	std::remove(filename);

	auto pfile = make_own<logger_file>();
	pfile->initialize({ std::string_view(filename) });
	auto phub = make_own<logger_hub_archive>();
	phub->register_log_targetable(pfile);
	phub->initialize();
	set_default_logger(phub);

	std::atomic<int> ready{ 0 };
	std::atomic<bool> go{ false };
	std::vector<std::thread> th;
	for (int t = 0; t < _threads; ++t)
		th.emplace_back([&, t]()
		{
			++ready;
			while (!go.load()) {}
			for (int i = 0; i < _logs_per_thread; ++i)
				LOG_INFO << "bench log message thread "sv << t << " index "sv << i;
		});
	while (ready.load() != _threads) {}

	const auto t0 = std::chrono::steady_clock::now();
	go.store(true);
	for (auto& x : th) x.join();
	reset_default_logger();
	phub->destroy();		// - drains the queue to the file logger
	pfile->destroy();		// - completes the file writes
	const auto t1 = std::chrono::steady_clock::now();

	std::remove(filename);
	return std::chrono::duration<double, std::nano>(t1 - t0).count() / (double(_threads) * _logs_per_thread);
}

int main(int argc, char** argv)
{
	const int threads = (argc > 1) ? std::atoi(argv[1]) : 1;
	const int logs = (argc > 2) ? std::atoi(argv[2]) : 1'000'000;
	const int rounds = (argc > 3) ? std::atoi(argv[3]) : 5;

	std::vector<double> v;
	for (int r = 0; r < rounds; ++r)
		v.push_back(run_once(threads, logs, r));
	std::sort(v.begin(), v.end());
	std::printf("RESULT threads=%d logs/thread=%d rounds=%d : median %.1f ns/log (min %.1f, max %.1f)\n", threads, logs, rounds, v[v.size() / 2], v.front(), v.back());
	return 0;
}
