인수인계 문서의 남은 일 (2026-10-22)
  • io_uring completion 모드 — 송수신 op 전환은 끝남(RECV / multishot + provided buffer / SENDMSG / SEND_ZC, buffered 포함 r11494, CQE 배치 끝 송신 r11497). 32 코어 공정 벤치에서 epoll 보다 빠름(tcp 64B x32 +14%, UDS +78%). 남은 것 : 8 코어·실 NIC 재측정, ASan / valgrind, 기본값은 아직 epoll.
  • completion 소유 worker 송신 op(CGDK_IO_URING_SEND_OP=1, 기본 off) — 제출 전(staging)의 송신 op 를 같은 handler 의 graceful close 가 shutdown + cancel 로 지워 데이터를 잃을 수 있음. 켜지 말 것.
  • 풀 재사용 socket 의 송신 한도 — maximum_depth_of_send_buffer(n) / _bytes(n) 를 socket 에 걸면 풀로 돌아간 객체가 다음 접속에서도 그 값을 가진다(process_reset_sendable 은 SO_SNDBUF 만 되돌림, Windows 도 같음).
  • io_uring 간헐 실패 — 전체 스위트 3회 중 1회 재접속 관리자가 첫 실패 뒤 재시도 안 함, accept socket 정리 10 s 초과. uds.reconnect 간헐 실패, uds.uds_only 중 pure virtual call 1회(양 백엔드). epoll 은 3회 모두 통과.
  • Windows TFO — SYN 에 데이터를 싣는 접속+첫 send API 미구현. Linux TFO connect 거절이 on_disconnect 로 오는 것과 Ntcp_reconnect 재접속 예약의 관계 미확인.
  • 그룹 — on_member_* 안에서 다른 멤버 락을 잡으면 교착. 규칙으로만 막음.
  • _buffer_unreal.h — 실제 UE 빌드 미확인, FString 경로 문제 남음.
  • Linux UDP — r11392 이전 트리에서 Nudp 수신 불가. 해당 프로젝트 확인 필요.
