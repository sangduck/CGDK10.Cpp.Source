** 게임방법 **

블랙잭 게임은 플레이어가 받은 카드의 합계가 딜러보다 높으면 이기는 게임입니다.
단 합계가 22 이상이면 무조건 집니다. 즉 최대 점수는 21입니다.
또한 에이스(Ace=A) 카드는 1로도 사용할 수 있고, 11로도 사용할 수 있는 독특한 성격을 가지고 있습니다.

1. [Deal] : 카드 섞어서 나누어주기
2. [Hit] : Player가 카드를 하나 더 받음. 합계가 Dealer와 Player 창에 표시됨.
3. [Stand] : 카드를 그만 받고 펴봄. 결과 확인 후 Player의 합계가 Dealer보다 높으면 이김.
4. [Score] : 승리 회수. 음수(-)로 표시되면 그 수만큼 진 것임.
